1. What are the main differences between XMLHttpRequest and Fetch API?
XMLHttpRequest uses event handlers such as onreadystatechange to handle requests and responses. 
The Fetch API uses Promises and supports methods such as .then() and .catch(), making asynchronous requests easier to manage.

2. Why is the Fetch API considered more modern and readable?
The Fetch API is considered more modern because it uses a cleaner syntax, Promises, and supports async/await. 
This makes the code easier to read, understand, and maintain.

3. What is the purpose of the .then() and .catch() methods in Fetch?
The .then() method handles the successful result of a Promise, such as receiving and processing server data. 
The .catch() method handles errors, such as network failures or errors thrown while processing the response.

4. What happens when you send a POST request to the placeholder API?
When a POST request is sent to JSONPlaceholder, the API simulates creating a new post and returns the submitted data with a generated ID,
usually 101 for this example. However, the post is not permanently stored on the server.
